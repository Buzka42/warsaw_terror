- **What we found**
  - **Official source exists and is in-force:** GSC lists “EWSS CAMF v1.2 | March 2026” as the current in-force EWSS document, at `https://www.gsc-europa.eu/sites/default/files/sites/all/files/EWSS-CAMF_in_force.pdf` — note the filename is `_in_force`, not `_v1.2`. The PDF cover/change-record say Issue 1.2, March 2026, with v1.1 Dec 2025 and v1.0 Dec 2023 predecessors. The archived GSC page lists v1.1 as no-longer-in-effect.
  - **Payload is 122 bits = 105 mandatory + 17 optional:** CAMF “is based on 122 bits”, split as Message identifier 16 + Hazard 9 + Hazard chronology 17 + Instructions 14 + Target Area 49 + Additional parameters 17. Field order A1→A18 is: A1 Message type, A2 Country, A3 Provider, A4 Hazard, A5 Severity, A6/A7 Onset, A8 Duration, A9/A10/A11 Instructions, A12–A16 Target Area, A17/A18 Additional. Bit widths: A1=2, A2=9, A3=5; A4=7, A5=2; A6=1, A7=14, A8=2; A9=1, A10=3, A11=5+5; A12=16, A13=17, A14=5, A15=5, A16=6; A17=2, A18=15.
  - **A1 Test/Alert/Update/All-Clear:** `00 Test, 01 Alert, 10 Update, 11 All Clear`. Test hazard is separate: A4 `1110001 OTHER – Test alert`【
